# CivilBuild — Civil Engineering Website

A responsive Civil Engineering and Construction website built with HTML, CSS and JavaScript.

## Features
- Responsive modern design
- Engineering services
- Construction materials library
- Project showcase
- Contact form demo
- No build tools or npm dependencies

## GitHub Pages
This project is ready for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
